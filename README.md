# Parallel programming

This repository contains training material for sessions on parallel
programming using OpenMP, MPI and TBB.

This is material for C/C++ and Fortran.

**Note: this is work in progress**

The training on MPI and OpenMP is based on material developed by Rolf
Rabenseifner (HLRS).  I attended his train-the-trainer program.

The slides for the MPI training can be downloaded 
* [Slides without animation](https://fs.hlrs.de/projects/par/par_prog_ws/pdf/mpi_3.1_rab.pdf)
* [Slides with animation](https://fs.hlrs.de/projects/par/par_prog_ws/pdf/mpi_3.1_rab-animated.pdf)


## What is it?

1. `source-code`: directory that contains the source code used
   during presentations and exercise sessions.
1. `LICENSE`: license for this repository's material.
1. `CONTRIBUTING.md`: how to contribute to this material.
